# YT-Chat-Categorizer

Extract and categorize YouTube links from WhatsApp chat exports using AI.

## What it does
- **Input**: A WhatsApp chat export file (`.txt`) containing shared YouTube links.
- **Output**: A cleaned, categorized list of videos, classified by topic (e.g., Education, Entertainment, Music) using LLM-powered analysis.

## How to use it
1.  Open `index.html` in your browser.
2.  Configure your API provider (OpenAI, Gemini, etc.) and enter your API key.
3.  Upload your WhatsApp `.txt` export.
4.  The tool will extract all YouTube links and use the chosen AI model to categorize them into a searchable dashboard.
